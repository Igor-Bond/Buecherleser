# Bücherleser

**Приложение:** https://igor-bond.github.io/Buecherleser/

Читалка для тех, кто учит немецкий: открывает книги fb2 и по нажатию на слово или выделению фразы даёт развёрнутый ответ — из встроенного словаря или от ИИ.

Работает в браузере на телефоне и компьютере, книги и словари хранятся на устройстве.

## Возможности

- Книги fb2, fb2.zip, epub (без DRM) и txt; оглавление, сноски, запоминание места.
- Карточка слова: начальная форма, род, множественное число, формы глагола, перевод.
- Немецкая морфология: отделяемые приставки (*stand … auf* → *aufstehen*), словоформы, составные слова.
- Разбор фразы по словам и ИИ-разбор в контексте (нужен свой ключ Google Gemini — бесплатный — или Claude).
- Оформление: темы, свои цвета, шрифты, интервалы, поля, страницы или прокрутка.
- «Мои слова» с экспортом в Anki, CSV и JSON.
- Словари: встроенный немецко-русский (около 92 тысяч статей), подключение StarDict, TSV и JSON.
- Три книги «Lesen B1»: варианты заданий по чтению в формате экзамена DTZ с проверкой ответов и таймером. Вторая — «aktuelle Themen» — построена на темах, о которых пишут сдающие экзамен осенью 2026 года; третья — «Prüfungsniveau» — сложнее, с типами текстов как на экзамене.
- Встроенные книги для чтения уровня A2–B1: две об электротехнике и работе электрика, две о повседневной жизни.
- Синхронизация между устройствами через вход Google: место чтения, ответы Lesen, «Мои слова», оформление. То же самое сохраняется копией в файл.
- Ставится на главный экран и открывается в своём окне без адресной строки (строка состояния телефона остаётся видна), работает без сети.

## Запуск

```bash
node serve.mjs
```

Затем открыть http://localhost:5173. Сборка не нужна: это статические файлы, их можно выложить на любой хостинг.

## Устройство

- `index.html`, `css/app.css`, `js/app.js` — интерфейс.
- `js/german.js` — морфология, `js/dict.js` — словари, `js/fb2.js` — разбор книг, `js/llm.js` — ИИ-разбор.
- `js/lesen.js`, `js/tests/` — книги с заданиями Lesen B1 (v01–v20 — первая, v21–v28 — вторая, v31–v38 — третья); `node tools/check-tests.mjs` проверяет варианты.
- `js/sync.js` — снимок прогресса, слияние «новее побеждает», копия файлом и облако; `js/firebase.config.js` — проект Firebase (общий с wordschatz, своя ветка `users/{uid}/buecherleser`); `docs/firestore.rules` — образец правил доступа.
- `books/` — встроенные книги fb2; `assets/` — иконки, пересоздаются скриптом `tools/make-icons.ps1`.
- `data/base-de-ru.txt` — встроенный словарь; пересобирается командой `node tools/build-dict.mjs <de.jsonl.gz> <ru.jsonl>`.
