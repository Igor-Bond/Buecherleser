# Sprechen B1

Приложение для подготовки к устной части экзамена DTZ (Deutsch-Test für Zuwanderer, A2–B1). Работает в браузере, ставится на телефон отдельным значком, ничего не требует, кроме микрофона и — для разбора ответов и партнёра — бесплатного ключа Google Gemini.

- **Phrasentrainer** — готовые фразы голосом. Ступени: повторить за голосом → текст с пропусками → по памяти → ответ на реплику собеседника. Пройденное возвращается через 1, 3, 7, 14 и 30 дней. Засчитывается любая из принятых формулировок; фразы о себе строятся из «Моих данных».
- **Aufgaben** — восемь наборов по три задания: рассказ о себе, описание фотографии, совместное планирование. Запись ответа, самопроверка по списку, образец, который читает голос, разбор ошибок от ИИ.
- **Партнёр-ИИ** в Teil 3: отвечает голосом за второго кандидата, спорит и предлагает своё.
- **Prüfung** — три части подряд: вопросы задаёт голос, идёт время, в третьей части отвечает партнёр-ИИ.
- **Redemittel** — справочник фраз и порядок экзамена.

Произношение автоматически не оценивается: ИИ видит только распознанный текст. Распознавание речи и ИИ требуют интернета. Прогресс и настройки хранятся только на устройстве.

## Устройство

Чистый JavaScript без сборки. `index.html`, `app.js` (экраны, микрофон, сохранение), `app.css`, `sw.js` (офлайн-кеш), `js/views.js` (разметка экранов), `js/trainer.js` (тренажёр: ступени, расписание, сверка с распознанной речью), `js/data/` (наборы s01–s08, фразы, справочник), `js/speak.js` и `js/voicein.js` (синтез и распознавание речи), `js/llm.js` (запросы к ИИ), `js/db.js` (хранилище), `assets/` (фотографии).

Проверки: `node tools/check.mjs` — формат наборов, фраз и расписание повторений; `node tools/check-precache.mjs` — офлайн-кеш. Значок рисует `node tools/make-icon.mjs`. При каждом изменении нужно поднять номер в `CACHE` в `sw.js`.
